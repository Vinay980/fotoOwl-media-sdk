FotoOwl Media UI Components

Reusable React media UI components designed around application-owned data and callbacks.

The UI package does not know about Pexels, authentication, or the media SDK. Consumers provide media data and behavior through props and headless APIs.

Installation

pnpm add @fotoowl/media-ui-react

MediaCard

import { MediaCard } from "@fotoowl/media-ui-react";

<MediaCard
  media={media}
  onSelect={setSelectedMedia}
  className="media-card"
  imageClassName="media-card-image"
/>

A selectable media item with keyboard activation through Enter and Space. Custom content can be supplied through children.

MediaGrid

import { MediaGrid } from "@fotoowl/media-ui-react";

<MediaGrid
  items={items}
  onSelect={setSelectedMedia}
  hasNextPage={hasNextPage}
  loadingMore={loadingMore}
  onLoadMore={loadMore}
/>

The grid renders media items and exposes load-more behavior through application callbacks. It does not own the data-fetching state machine.

Headless grid API

import { useMediaGrid } from "@fotoowl/media-ui-react";

const { items, getRootProps, getItemProps } = useMediaGrid({
  items,
  onSelect: setSelectedMedia,
});

return (
  <div {...getRootProps()}>
    {items.map((media) => (
      <div key={`${media.type}-${media.id}`} {...getItemProps(media)}>
        {/* consumer-owned markup and CSS */}
      </div>
    ))}
  </div>
);

Prop-getters expose interaction and accessibility behavior while the consumer owns markup and styling.

MediaSearch

<MediaSearch
  initialQuery={query}
  loading={loading}
  onSearch={handleSearch}
/>

The component trims submitted queries, rejects empty submissions, prevents duplicate submission while loading, and never performs network requests itself.

MediaLightbox

<MediaLightbox
  media={selectedMedia}
  onClose={() => setSelectedMedia(null)}
/>

The lightbox supports image and video content, dialog semantics, an accessible close button, Escape-to-close behavior, and focus restoration.

MediaReel

<MediaReel
  items={items}
  activeIndex={activeIndex}
  onActiveChange={(index, media) => {
    setActiveIndex(index);
  }}
/>

The reel uses visibility detection to report the active item. Consumers can provide the vertical snap CSS/markup contract appropriate to their application.

Styling contract

The package does not require a CSS framework and does not impose an application visual design system. Consumers can supply className and component-specific class props or use custom children/headless APIs.

Accessibility

  • Selectable cards support keyboard activation.
  • Images expose meaningful alt text.
  • Search uses native form semantics and an accessible label.
  • The lightbox exposes dialog semantics and keyboard close behavior.
  • Video content receives an accessible label.

Architecture

Application
├── media-react        → data/auth/events
└── media-ui-react     → presentation/interaction

Components receive data and callbacks as props. They do not import media-core or media-react.
