FotoOwl Media SDK

Framework-agnostic TypeScript media SDK backed by the Pexels API.

The core package contains no React, DOM, or React Native dependencies. Platform wrappers adapt the core SDK to React and React Native.

Installation

pnpm add @fotoowl/media-core

Create a client

import { createMediaClient } from "@fotoowl/media-core";

const client = createMediaClient({
  apiKey: "YOUR_PEXELS_API_KEY",
});

Search

const result = await client.search({
  query: "nature",
  type: "photo",
  page: 1,
  perPage: 20,
});

Search supports photo, video, or combined media requests. Results are normalized into SDK-owned types.

Curated media

const result = await client.curated({
  page: 1,
  perPage: 20,
});

Get a media item

const result = await client.getById("123");

Typed models

The core exports MediaItem, MediaPage, media types, API result types, event types, MediaError, MediaClient, and createMediaClient.

Pagination

Search and curated results expose page information and whether another page is available. Consumers can request the next page explicitly or use the React hook's loadMore() helper.

Caching and request de-duplication

The client provides in-memory caching with configurable TTL support. Concurrent requests for the same resource can share an in-flight request instead of issuing duplicate network calls.

Events

const unsubscribe = client.on("view", (event) => {
  console.log(event.media);
});

client.trackView(media);
client.trackDownload(media);

unsubscribe();

The SDK supports view and download activity events. Subscriptions return an unsubscribe function, and the SDK also has a default console listener for activity events.

Error handling

SDK failures are represented by the typed MediaError contract rather than exposing raw provider-specific errors to consumers.

React integration

import {
  MediaProvider,
  useMediaSearch,
} from "@fotoowl/media-react";

<MediaProvider apiKey={apiKey}>
  <App />
</MediaProvider>

function Results() {
  const { data, loading, error, hasNextPage, loadMore } =
    useMediaSearch({
      query: "nature",
      type: "photo",
      perPage: 20,
    });

  // render data.items and use loadMore() for pagination
}

The React package exports MediaProvider, useMediaClient, useMediaSearch, and useMediaItem. The wrapper adapts the framework-agnostic core and does not replace it.
